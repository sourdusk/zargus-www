Zargus webhook setup

Get instant push alerts from your Zabbix server to the Zargus app. Takes about two minutes.

1. Download the media type template (right-click → save).
2. In Zabbix: Administration → Media types → Import (arrow icon, top right). Upload the file. This creates the "Zargus push" media type with everything pre-configured.
3. Open the imported media type and replace three parameter values with the ones shown in the app under Settings → Zargus Cloud:
  • endpoint — your push endpoint URL
  • apiKey — your API key
  • topic — your account ID
Also set serverName to whatever label you want the server to show as in the app. Save.
4. User settings → Media → Add — type "Zargus push", any "send to" value. Without this step nothing fires.
5. Configuration → Actions → Trigger actions — create an action that sends a message via "Zargus push" to your user, with Problem, Recovery, and Update operations all enabled.
6. Fire a test problem and feel it on your phone.

Self-hosted instead?

If you run your own relay or use ntfy, the same template works: set mode to ntfy and point the parameters at your own infrastructure. Details in the app's repository documentation.

Notes

The webhook script is compatible with Zabbix 6.0 through 7.4+ (handles both HTTP object generations). Messages carry only problem names, hosts, and severity — no credentials — and the app treats every push as a ping: it immediately syncs against your Zabbix API, which stays the source of truth.
